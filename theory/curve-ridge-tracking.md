# 沿曲线连续性追踪主簇：剔除平行的离群带子

清洗一批测量曲线时碰到最难缠的一种脏数据：散点曲线上叠了一条**平行的离群带子**，而且在某些 x 区间里带子的点数能占到 45%，个别箱甚至过半。这时候前面两套方法都不够用了——分箱中位数会被局部污染劫持，DBSCAN 的"保留最大簇"在带子更密的区间必然选错。

本文记录第三套方法：按 x 分箱做一维聚类，然后**利用曲线沿 x 连续这个先验**，从锚点向两边追踪主簇，而不是按簇大小挑。以及实现时踩的一个关键坑：间隙阈值的尺度不能只从局部数据估。

## 为什么"保留最大簇"会失效

密度聚类之后总要决定哪个簇是"真数据"，最省事的判据是点数最多。这个判据隐含假设"真数据永远比噪声多"。

这个假设是逐区间成立还是全局成立，差别很大。全局看主曲线占 80%，但带子在某段 x 上很集中，局部占比能到 45%~55%。一旦某个区间里带子更密，按点数挑就会在那一段选中带子，主曲线反而被当噪声删掉。结果是清洗后的曲线在中间某段突然"跳"到带子上去，形状被破坏。

## 换一个先验：连续性

正确的先验不是"谁点多"，而是：

- **真曲线沿 x 连续**，相邻 x 位置的 y 变化平滑、有确定的斜率。
- **带子相对真曲线是突跳**，它虽然自己也连续，但和主曲线之间隔着一个固定的间隙。

这个先验对局部污染率完全免疫。只要在某一处能确定主曲线在哪，就能顺着连续性一路推下去，哪怕途中某几箱带子的点更多。

## 算法步骤

1. **分箱 + 箱内一维聚类**。按 x 分箱，每箱内把 y 排序，相邻间距超过阈值就断开。这等价于一维的 DBSCAN，但实现只要一次排序加一次 diff。
2. **选锚点**。挑那些"只有一个簇"的箱（无歧义，说明该处没有带子），在其中取点数最多的一箱作为起点。
3. **向左右传播**。每前进一箱，用上一箱的信息预测本箱主簇的位置，挑离预测值最近的簇：

   ```text
   predict = last_center + slope * dx
   pick    = argmin |cluster_center - predict|
   ```

4. **斜率平滑与急弯保护**。斜率用指数平滑更新 `slope = 0.5 * slope + 0.5 * new_slope`，避免单箱噪声把预测方向带歪。如果本箱选中的簇相对预测值跳变超过 `jump_k * sigma`，仍然取最近的簇，但**不更新斜率**——这一步是给曲线本身的急弯留余地，急弯处预测必然不准，不该让它污染斜率状态。

每箱里点数小于 `min_cluster`（取 3）的簇直接当噪声丢掉。这样孤立散点在同一步就剔掉了，不需要额外一遍阈值过滤。

sigma 也是逐箱估的，这点很有用：低功率端本来就散、压缩区本来就紧，同一个 k 值在两端不会一头删太多一头漏太多。

## 踩坑：间隙阈值只用局部间距，主曲线会被切碎

第一版的间隙阈值取"箱内相邻点的典型间距"乘一个系数：

```py
gap_threshold = gap_k * np.median(np.diff(np.sort(y_in_bin)))   # 有问题
```

看起来很自然——用数据自己的尺度定阈值。结果保留率从 89% 崩到 25%。

原因是主曲线自身的噪声散布被切成了好几个簇，而每箱只留一个簇，于是每箱都丢掉大部分点。

根因在于**排序间距的上尾很重**。n=60 个点、sigma=1.5 时，相邻间距的中位数约 0.15，但主体内部偶发的间隙能到 0.6~1.0——这是纯随机分布的正常现象，不代表有真实的簇边界。`gap_k=6` 时阈值只有 0.9，正好被这些偶发间隙击穿。

换句话说，中位间距衡量的是"点有多密"，而我需要的是"多大的间隙才算真断开"。后者应该由**噪声的物理尺度**决定。

## 解法：两段式尺度估计

先粗估一个不受污染的尺度，再用它约束阈值下限：

```py
sigma_noise = mad_of_trend_residual(x, y)          # 第一段：粗估噪声尺度
gap_threshold = max(gap_k * typical_gap, 4 * sigma_noise)
```

`sigma_noise` 用（已经加了跨箱中值滤波的）趋势残差 MAD 估出来，代表主曲线的噪声宽度。真实的簇边界间隙必然远大于噪声宽度，`4 * sigma` 是个安全的下限。

改完之后：保留率回到 89~90%，带子残留 0，6 个频点的峰值全部不变。

这种"先粗估尺度，再用尺度做判据"的两段式，在没有先验尺度的聚类问题里很通用。纯粹从待聚类数据自己估尺度是循环论证——数据被污染了，估出来的尺度也是错的。得找一个相对不受污染的量（稳健统计量、物理约束、已知的测量精度）来打底。

## 三套方法的分工

| 方法 | 擅长 | 失效于 |
| --- | --- | --- |
| 分箱中位数 + MAD 阈值 | 零星散点，参数少可控 | 局部污染接近 50% |
| 残差空间 DBSCAN | 成片的平行结构 | 局部区间里带子更密时选错簇 |
| 逐箱连续性追踪 | 局部污染过半的带子 | 曲线本身不连续（有跳变的物理量） |

实际用的是第一套打底、第三套处理带子。第二套在这份数据上被第三套取代了，但在"离群结构不平行、形状不规则"的场景仍然有用。

## 小结

清洗算法的核心不是选哪个聚类器，而是**把领域先验写进判据**。"曲线连续"这个先验一旦用上，局部污染率就不再是约束条件了；而只要还在用"点多的是真数据"，无论换什么聚类器都会在同一个地方翻车。
